# FolderNumberer
A Windows-based numbering and sorting program that supports automatic sorting by file format and undo, with format conversion planned for the future.

# **English**
# FolderNumberer
A lightweight Windows desktop utility developed in C#, designed to help users quickly number and organize files in batches.
## ✨ Features
- **Automatic sorting**: Supports automatic classification and numbered sorting by file format.
- **Safe undo**: Supports one-click undo. If you accidentally sort incorrectly, you can restore the state before sorting at any time.
- **Future plans**: Subsequent versions plan to add file format conversion.
- **Portable and installation-free**: Download the `.exe` file and double-click to run; no installation required.
## 🚀 How to Use
1. Click the [Releases](../../releases) tab on the right side of this page.
2. Find the latest release (e.g., `v1.0.0`) and download `FolderNumberer.exe` from "Assets".
3. Double-click `FolderNumberer.exe` to run it.
4. Follow the on-screen instructions, select the folder you want to organize and sort, and click Start.
## 🛠️ Tech Stack
- **Language**: C# (.NET)
- **Development tool**: Visual Studio
- **Platform**: Windows
